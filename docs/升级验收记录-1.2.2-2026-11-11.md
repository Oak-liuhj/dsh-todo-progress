# 1.2.2 / DSH 0.2.2-rc.1 升级验收

日期：2026-11-11（北京时间）。宿主为本机官方桌面客户端及其捆绑 CLI，`dsh --version` 返回 `0.2.2-rc.1`。

## 问题与变更

1.2.1 的 `engines.dsh` 仅接受 `0.2.1-rc.5`，新版宿主将其标为异常并拒绝装配。本次将插件升为 1.2.2，兼容值显式列出 `0.2.1-rc.5 || 0.2.2-rc.1`，并带上已有的能力隔离、布局和清理容错；没有使用 `allow-version` 或关闭宿主版本检查。

## Web 实机

- 使用隔离的 `DSH_HOME`、官方 CLI、回环地址 3081、本地 OpenAI 兼容模型夹具；不使用用户模型凭据。
- 空白会话可从右上角打开面板，显示原定 `todo_write` 引导文案。
- 经真实模型工具调用写入三个待办：完成 1、进行中 1、待办 1，界面显示 33%，当前第 2 步；筛选进行中时仅保留对应项。
- 再次点击入口复用同一任务页；工具引导入口同样能打开任务页。
- 1440px 视口下保留窄侧栏与 300px 下限，任务正文实测约 299px（边框占用另计）。
- 从插件菜单新建会话，成功跳转空白会话，任务进度变为 0/0，原会话未删除。
- 上述操作后浏览器控制台没有警告或错误记录。

## 本机桌面

- 更新前备份 profile 清单、锁文件、覆盖配置、旧插件以及手工依赖清单。更新使用宿主官方 `plugin add`，两个手工依赖仍存在。
- 正常退出并重开客户端后，右上角“任务”入口恢复；已有会话的 6 项待办、100% 完成状态、30 分钟自动收起偏好保留，展开可查看原任务列表。
- 使用说明显示 1.2.2，确认实际渲染新客户端。
- 本次未向日常会话的外部模型发送消息；新的工具写入与新建会话在隔离 Web 验证。

桌面截图及包含真实会话内容的日志仅保留在本机 `.local-validation/upgrade-1.2.2/`，不随发布包上传。
